# 廍子國小段考進度看板

Emily AI Studio 製作的靜態段考看板 GitHub Pages 專案。

## 使用方式

部署後開啟 GitHub Pages 網址即可使用。教師設定保存在目前瀏覽器的 localStorage，不會同步到其他裝置。英語聽力 MP3 只透過本機檔案選取，在目前頁面暫存播放；不會上傳到 GitHub 或寫入 localStorage，因此播放不會增加 GitHub Pages 的音檔流量。關閉頁面或重新整理後需重新選取。

## 本機預覽

直接以 Chrome 開啟 `index.html`。如瀏覽器限制本機字型或音檔讀取，可使用靜態本機伺服器預覽。

## GitHub Pages

儲存庫使用 GitHub Actions 部署至 GitHub Pages。每次推送至 `main` 後會自動更新網站。

## 字型授權

注音字型與相關授權、聲明檔保存在 `assets/fonts/`。
